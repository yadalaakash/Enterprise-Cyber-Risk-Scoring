Enterprise Cyber Risk Scoring Using Multi-Model Ensemble Classifier

Project Overview

This project develops an AI-powered Enterprise Cyber Risk Scoring Platform using a Multi-Model Ensemble Classifier.

It combines Network Security, Endpoint Security, and Email Security signals to calculate an overall enterprise cyber risk score.

The platform provides a centralized SOC dashboard to help security teams monitor threats, analyze risks, and support security decision-making.

Key Features

- Network Security Monitoring
- Endpoint Security Analysis
- Email Security Monitoring
- AI-Based Ensemble Prediction
- Enterprise Risk Score Calculation
- CISO Security Dashboard
- Risk Assessment Reports
- Scan History
- Security Telemetry Analysis

Machine Learning Models

- Random Forest
- Decision Tree
- Logistic Regression
- Multi-Model Ensemble Classification

Technology Stack

Backend: Python, Flask

Frontend: React.js, JavaScript, HTML, CSS

Machine Learning: Scikit-learn, Pandas, NumPy

Database: SQLite

Development Tools: VS Code, Git, GitHub

Project Architecture

1. Collect network, endpoint, and email security data.
2. Preprocess and combine security features.
3. Apply machine learning models.
4. Generate an overall cyber risk score.
5. Display security insights through the SOC dashboard.

How to Run the Project

Backend

pip install -r requirements.txt

Frontend

cd frontend
npm install

Start Application

Run the following Windows batch file from the project root:

start_all.bat
